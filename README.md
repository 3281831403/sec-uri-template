sec-uri-template
====================

链接预览与跳转服务把用户提交的模板直接拼成目标地址，最近出现编码后的地址被下游二次解码、以及只看主机不看协议造成的跳转劫持：契约要求模板按花括号切成字面量与表达式两类片段，表达式由操作符与逗号分隔的变量组成，变量名只允许字母、下划线与数字且不得以数字开头，变量可带星号表示逐项展开，遇到未闭合的花括号、空表达式或非法变量名必须报错并给出固定原因（unclosed-expression、empty-expression、invalid-varname），合法模板的校验结果为空列表；展开时未定义的变量整体消失、值为空串时仍参与但按名值型操作符的规则只输出名字而不带等号；普通扩展只保留非保留字符，其余字节按 UTF-8 大写十六进制百分号编码，空格必须编码成 %20 而不是加号；保留扩展与片段扩展必须保留保留字符（含冒号、斜杠、问号、井号、方括号、@ 与子分隔符）不再编码；片段扩展以井号开头，标签扩展以点开头，路径扩展以斜杠开头，参数扩展以分号开头，查询扩展以问号开头、后续查询以 & 开头；列表变量默认用逗号连接，带星号时按操作符的分隔符逐项展开（路径用斜杠，查询与参数重复键名）；所有变量都未定义或为空列表时不输出操作符前缀；对外暴露的单值编码按 simple、reserved、label、path、query 五种风格选择字符集，reserved 风格保留保留字符，未知风格报错；安全展开在展开后解析结果，协议必须是 http 或 https、授权段不得含 userinfo、主机名大小写不敏感且必须在允许列表内、缺失主机同样拒绝，任一不满足即报错。不变量：同一模板与变量多次展开结果逐字符相同；未定义变量不产生任何字符；保留扩展不改变保留字符；查询展开的键顺序与模板中变量顺序一致。
